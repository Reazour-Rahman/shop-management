# হাজিরা সিঙ্ক প্রোগ্রাম (দোকানের কম্পিউটারের জন্য)

মেশিন (Hikvision DS-K1T343EFWX) নিজের ভেতরে সব হাজিরা জমিয়ে রাখে। এই প্রোগ্রাম মেশিন থেকে হাজিরা তুলে ওয়েবসাইটে পাঠায়।
কম্পিউটার বন্ধ থাকলে কিছু হারায় না। চালু হলে প্রোগ্রাম যেখানে থেমেছিল সেখান থেকে বাকি সব পাঠিয়ে দেয়।
একই হাজিরা দুইবার গেলেও ওয়েবসাইট একবারই রাখে।

## একবারের সেটআপ

### ১) ওয়েবসাইটে গোপন কী (ATTENDANCE_KEY) বসান
কী বানাতে যেকোনো কম্পিউটারে এই কমান্ড চালান:

    node -e "console.log(require('crypto').randomBytes(24).toString('hex'))"

যে লম্বা লেখা আসবে (কমপক্ষে ১৬ অক্ষর) সেটাই কী।
- নিজের কম্পিউটারে চালালে `.env` ফাইলে যোগ করুন: `ATTENDANCE_KEY=এখানে_কী`
- Vercel-এ: Project → Settings → Environment Variables → `ATTENDANCE_KEY` নামে একই কী যোগ করে Redeploy করুন।
এই কী কাউকে দেবেন না, আর কোথাও পোস্ট করবেন না।

### ২) মেশিনে কর্মী যোগ করুন
- প্রতিজন কর্মীর **Employee No** ঠিক ওয়েবসাইটের Employee ID-র সংখ্যার সমান দিন। E-0001 হলে মেশিনে 1, E-0007 হলে 7।
- অন্যরকম নাম্বার দিয়ে ফেললে ওয়েবসাইটের Employees পেজে ওই কর্মীর **Attendance machine ID** ঘরে মেশিনের নাম্বারটা লিখুন।
- মেশিনের সময় ও তারিখ ঠিক রাখুন (বাংলাদেশ সময়)। সময় ভুল হলে হাজিরার সময়ও ভুল আসবে।
- মেশিনের IP যেন বদলে না যায়: রাউটারে মেশিনের জন্য স্থির IP (DHCP reservation) দিন।
- মেশিনের ওয়েব পেজে ISAPI বা Integration Protocol-এর কোনো অপশন থাকলে সেটা চালু রাখুন।

### ৩) দোকানের কম্পিউটারে
1. nodejs.org থেকে **Node.js LTS** (১৮ বা নতুন) ইনস্টল করুন।
2. এই `attendance-agent` ফোল্ডারটা কম্পিউটারে রাখুন, যেমন `C:\attendance-agent`।
3. `config.example.json` কপি করে নাম দিন `config.json`, তারপর Notepad-এ খুলে ভরুন:
   - `deviceUrl`: মেশিনের IP, যেমন `http://192.168.1.64`
   - `deviceUser`, `devicePassword`: মেশিনের অ্যাডমিন নাম ও পাসওয়ার্ড
   - `websiteUrl`: আপনার ওয়েবসাইটের ঠিকানা
   - `apiKey`: ধাপ ১-এর কী
4. পরীক্ষা: ওই ফোল্ডারে Command Prompt খুলে `node agent.js --once` চালান। "Sent … punches" বা "No new punches" এলে ঠিক আছে।
5. `install-autostart.bat` একবার ডাবল ক্লিক করুন। এরপর কম্পিউটার চালু করে সাইন ইন করলেই প্রোগ্রাম নিজে চলবে।

`config.json`-এ পাসওয়ার্ড আছে। এই ফাইল কাউকে পাঠাবেন না, আর কোথাও আপলোড করবেন না।

## নিয়মিত ব্যবহার
- ওয়েবসাইটে HR & Payroll → **Attendance**।
- "Rules and machine" ট্যাবে দেখা যায় শেষ কখন কম্পিউটার থেকে ডেটা এসেছে।
- কেউ পাঞ্চ করতে ভুলে গেলে Daily ট্যাবে তার সারির **Punches** বাটন থেকে সময় হাতে যোগ করা যায়।

## সমস্যা হলে
প্রোগ্রাম যা করছে তা `agent.log` ফাইলে লেখা থাকে।

| বার্তা | কী করবেন |
|---|---|
| The machine did not answer | মেশিন চালু কি না, IP ঠিক কি না, কম্পিউটার ও মেশিন একই রাউটারে কি না দেখুন |
| The machine refused the user name or password | `config.json`-এ মেশিনের নাম/পাসওয়ার্ড মিলিয়ে নিন |
| Wrong key / 401 | `apiKey` আর ওয়েবসাইটের `ATTENDANCE_KEY` একই কি না দেখুন, Vercel-এ বদলালে Redeploy করুন |
| ATTENDANCE_KEY is not set | ওয়েবসাইটে কী বসানো হয়নি (ধাপ ১) |
| The machine replied 404 | মেশিনে ISAPI চালু নেই, অথবা IP অন্য কোনো ডিভাইসের |
| ওয়েবসাইটে "Punches came from machine ID …" | ওই কর্মীর Attendance machine ID ঠিক করুন |
